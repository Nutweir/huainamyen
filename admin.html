1 · เชื่อมต่อ GitHub

ยังไม่มี token? สร้างครั้งเดียว (ประมาณ 2 นาที)
  1. เปิด github.com/settings/personal-access-tokens/new ↗
  2. ตั้งชื่อ เช่น journal admin และเลือกวันหมดอายุ
  3. Repository access → Only select repositories → เลือก huainamyen
  4. Permissions → Repository permissions → Contents: Read and write
  5. กด Generate token แล้วคัดลอกมาวางด้านบน
